# Titans: Learning to Memorize at Test Time

> 来源文件：`titans.pdf` · 整理自 DeepSeek 对话阅读笔记 · [返回综述](../survey.md)

好的，我已仔细阅读并分析了您提供的论文《Titans: Learning to Memorize at Test Time》。

这是一篇来自 Google Research 的研究工作，提出了一个能够在测试时学习记忆的神经长期记忆模块，并基于此设计了名为 Titans 的新型序列建模架构。

以下是对该论文核心内容的系统分析与总结：

## 1. 核心问题与动机

论文指出现有序列建模架构存在根本性矛盾：

Transformer（纯注意力）：能够精确建模所有 token 之间的依赖关系，但计算和内存复杂度随上下文长度呈二次增长，无法有效处理极长序列。

线性 RNN / 线性 Transformer：通过将历史压缩到固定大小的向量或矩阵状态中，实现线性复杂度，但压缩能力有限，在极长上下文中会出现“记忆溢出”，性能显著下降。

```
  现有记忆模块：大多基于“瞬时惊讶”（momentary           surprise）更新，缺乏对   token 流的考

  虑，且缺少遗忘机制，导致记忆管理不佳。

论文从人类记忆系统获得灵感：人类记忆不是单一过程，而是由短期记忆、工作记忆、长期记忆
等多个相互独立又相互连接的模块组成。注意力负责精确的短期依赖建模，而神经长期记忆负责

存储和抽象历史信息。

因此，论文提出五个核心问题：

  Q1：什么是好的记忆结构？

  Q2：什么是合适的记忆更新机制？

  Q3：什么是好的记忆检索过程？

  Q4：如何设计一个高效架构来整合不同的记忆模块？

  Q5：是否需要深度记忆模块来有效存储长期历史？

3. Titans 架构：如何整合记忆？

论文提出三种将神经长期记忆整合到深度网络中的方式，对应三种                    Titans 变体：

3.1 核心组件

  Core（短期记忆）：有限窗口的注意力，负责当前上下文的精确建模。

  Long-term Memory（长期记忆）：神经长期记忆模块，负责存储/记忆长期历史。

  Persistent Memory（持久记忆）：一组可学习但数据无关的参数，编码任务知识。

3.2 三种变体

1. Memory as Context (MAC)：

    将长期记忆检索结果与持久记忆、当前输入拼接，送入注意力。

    注意力帮助长期记忆判断哪些信息值得存储。

    测试时：持久记忆固定，注意力进行上下文学习，长期记忆继续更新。

2. Memory as Gated (MAG)：

    一路用滑动窗口注意力，一路用神经记忆，通过门控融合。

    滑动窗口注意力作为精确短期记忆，神经记忆作为渐忘长期记忆。

3. Memory as Layer (MAL)：

    神经记忆作为一层，先压缩上下文，再送入滑动窗口注意力。

    更接近现有混合模型，但表达力受限于层间顺序。

3.3 无注意力版本（LMM）
神经记忆模块也可单独作为序列模型使用，不依赖注意力，验证其独立记忆能力。

理论优势：Titans   能够解决超出

4. 实验与主要结果

4.1 语言建模与常识推理

  在 340M、400M、760M    参数规模上，Titans   在困惑度和常识推理准确率上均优于

  Transformer++、RetNet、GLA、Mamba、Mamba2、DeltaNet、TTT、Gated    DeltaNet
  等。

  760M 规模下，Titans  (MAC) 平均准确率   52.51%，Titans (MAG) 52.50%，优于 Gated
  DeltaNet-H2（51.49%）和 Transformer++（48.69%）。

  混合模型（MAC、MAG、MAL）均优于          Samba 和 Gated DeltaNet-H2。

4.2 针尖寻针（NIAH）

  在 S-NIAH-PK、N、W   三个任务上，Titans   在 2K、4K、8K、16K   长度下均保持高准确

  率。

  88.4%、4.4%、0.0%；Mamba2    仅 5.4%、0.0%、0.0%；DeltaNet  71.4%、5.4%、

  0.0%。

  说明  Titans 能有效管理记忆容量，避免随长度增加而崩溃。

4.3 BABILong 基准

  在极长文档推理任务中，Titans       (MAC) 优于 GPT-4、GPT-4-mini、Llama3.1-8B+RAG、

  Mamba2-8B、RWKV-6-7B、RecurrentGemma-9B   等，且参数量少得多（约为        Llama3.1-
  8B 的 1/70）。

  微调设置下，Titans   也优于所有基线，包括       GPT-4。

  在 ETT、ECL、Traffic、Weather 等数据集上，神经记忆模块的         MSE/MAE 均优于  Simba、

5. 关键洞察

1. 测试时学习记忆是有效的：神经长期记忆模块能够在测试时持续更新参数，记住历史信息，

  而不过拟合训练数据。

2. 动量和遗忘机制至关重要：动量帮助管理跨时间的惊讶，遗忘门控制记忆容量，两者共同提
  升长上下文性能。

3. 深度非线性记忆优于线性记忆：MLP         记忆比矩阵值线性记忆表达力更强，在长序列上表现更

  好。

4. 架构设计影响性能：MAC      和 MAG  优于  MAL，说明将记忆作为上下文或门控分支比作为层

  更有效。
5. 可扩展到极长上下文：Titans     可有效扩展到超过      2M 上下文窗口，且在     NIAH 和 BABILong

  上保持高准确率。

6. 通用性强：在语言、时间序列、DNA         等多种任务上均取得优异结果。

7. 局限性与未来方向

  训练吞吐量：深度记忆模块略慢于           Mamba2 等高度优化模型，深度越深越慢。

  计算资源：虽然可并行训练，但训练大规模模型仍需大量算力。

  记忆深度与效率权衡：更深记忆效果更好，但训练和推理成本更高。

  评估范围：主要在语言建模、NIAH、BABILong、时间序列、DNA              上验证，尚未涉及多模

  态、对话系统等。

  未来方向：设计更高效的记忆架构；探索记忆模块与注意力更优的融合方式；扩展到更大规
  模模型和多模态任务；研究记忆模块在持续学习、个性化等场景中的应用。

8. 总结

Titans 的核心贡献在于，它提出了一种能够在测试时学习记忆的神经长期记忆模块，并基于此

设计了三种架构变体（MAC、MAG、MAL）。            该记忆模块通过惊讶度量、动量、遗忘机制和
深度  MLP，实现了对长期历史的高效压缩和存储。在语言建模、常识推理、NIAH、

BABILong、时间序列和    DNA 建模等任务上，Titans    均优于   Transformer 和现代线性循环模

型，并可扩展到超过       2M 的上下文窗口。这项工作与        MemoryLLM、M+、TTT、Gated
DeltaNet 等共同构成了从“外部记忆系统”到“模型内化记忆”、从“固定状态”到“测试时学习”的完

整技术演进图谱，标志着序列建模与记忆机制融合的重要进展。
```
