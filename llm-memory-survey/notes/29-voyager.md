# Voyager: An Open-Ended Embodied Agent with Large Language Models

> 来源文件：`voyager.pdf` · 整理自 DeepSeek 对话阅读笔记 · [返回综述](../survey.md)

好的，我已仔细阅读并分析了您提供的论文《Voyager: An Open-Ended Embodied Agent with Large Language Models》。这是一篇来自NVIDIA、Caltech等机构的研究工作，提出了首个由LLM驱动的、在Minecraft中进行开放式终身学习的具身智能体。

以下是对该论文核心内容的系统分析与总结：

## 1. 核心问题与动机

论文指出现有AI智能体在开放式环境中面临根本性挑战：缺乏终身学习能力，无法持续探索、获取新技能并积累知识。

传统RL/模仿学习：在原始动作空间上操作，难以进行系统性探索、可解释性差、泛化能力弱。

现有LLM智能体：虽然能利用预训练世界知识生成行动计划，但不是终身学习者，无法在长时间跨度内逐步获取、更新、积累和迁移知识。

论文以Minecraft为例，提出一个有效的终身学习智能体应具备：

## 1. 根据当前技能水平和世界状态提出合适任务（如沙漠中学采沙和仙人掌，而非森林中的

铁）；

## 2. 根据环境反馈精炼技能，并将掌握的技能存入记忆以供未来复用（如打僵尸与打蜘蛛相

似）；

## 3. 持续自我驱动地探索世界，寻找新任务。

## 2. 提出的方法：Voyager

Voyager由三个核心组件构成：

### 2.1 自动课程（Automatic Curriculum）

利用GPT-4的互联网规模知识，自底向上地生成一系列新任务。

输入提示包含：鼓励多样性的指令、智能体当前状态（库存、装备、附近方块/实体、生物群系、时间、生命值、饥饿值、位置）、已完成/失败任务、额外上下文（GPT-3.5自问自答）。

课程考虑探索进度和智能体状态，确保任务既有挑战性又可完成，可视为一种上下文形式的新奇搜索。

### 2.2 技能库（Skill Library）

每个技能以可执行代码表示，存储为向量数据库中的键值对：键是程序描述的嵌入向量（由GPT-3.5生成），值是程序本身。

技能可组合：复杂技能由简单程序合成，快速复合智能体能力，缓解灾难性遗忘。

技能检索：用自生成任务计划和环境反馈的嵌入查询技能库，检索Top-5相关技能。

### 2.3 迭代提示机制（Iterative Prompting Mechanism）

通过三种反馈进行自我改进：

## 1. 环境反馈：程序执行的中间进度（如“我还需要7个铁锭才能制作铁胸甲”）。

## 2. 执行错误：代码解释器揭示的无效操作或语法错误。

## 3. 自我验证：另一个GPT-4智能体检查任务是否成功，若失败则提供批评和改进建议。

迭代过程重复直到自我验证确认任务完成，然后将新技能加入技能库，并向自动课程请求下一个目标。

若4轮代码生成后仍卡住，则查询课程获取另一个任务。

## 3. 实验与主要结果

实验设置使用GPT-4、GPT-3.5、text-embedding-ada-002 API。

模拟环境基于MineDojo，使用Mineflayer JavaScript API进行运动控制。

基线：ReAct、Reflexion、AutoGPT（均重新实现以适配Minecraft）。

4. 关键洞察

1. 代码作为行动空间：程序天然表示时间延伸和组合动作，适合长程任务，且可解释、可复

  用。

2. 自动课程驱动开放探索：自底向上、好奇心驱动的课程使智能体持续进步，避免任务过难或

  过易。

3. 技能库实现终身学习：存储可执行代码，通过描述嵌入检索，技能可组合、可迁移，缓解灾
  难性遗忘。

4. 迭代提示实现自我改进：环境反馈+执行错误+自我验证三重反馈，使GPT-4能持续精炼代
  码。

5. 无参数更新：完全通过黑盒API查询和上下文学习，无需微调模型参数。

6. 零样本泛化：技能库在新世界中可复用，解决未见任务，基线无法泛化。

关键区别：Voyager的独特贡献在于将代码作为行动空间，结合自动课程、技能库和迭代提示，

实现无参数更新的终身学习。它不训练模型，而是通过GPT-4的上下文学习和代码生成能力，

让智能体在Minecraft中持续探索、学习、积累技能。这与ExpeL、AWM、ReasoningBank等
经验学习方法有相似之处，但Voyager的技能是可执行代码，更精确、可复用、可组合。

6. 局限性与未来方向

  成本：GPT-4   API比GPT-3.5贵15倍，但Voyager需要GPT-4的代码生成质量。

  不准确性：尽管有迭代提示，仍存在智能体卡住、自我验证失败的情况。

  幻觉：自动课程偶尔提出不可实现的任务（如“铜剑”），代码生成中也可能使用无效燃料或

  调用不存在的API。

  视觉感知缺失：当前GPT-4       API仅支持文本，Voyager无法直接感知视觉信息，需人类反馈辅
  助3D建筑。

  未来方向：集成多模态感知模型、微调开源LLM、降低API成本、扩展到机器人等物理领域。

7. 总结

Voyager的核心贡献在于，它提出了首个LLM驱动的Minecraft终身学习智能体，通过自动课

程、技能库和迭代提示机制，实现了持续探索、技能获取和零样本泛化。                      在Minecraft中，

Voyager获得3.3倍更多独特物品，解锁科技树速度快15.3倍，探索距离长2.3倍，并能将技能库
迁移到新世界解决未见任务。这项工作与ExpeL、AWM、ReasoningBank、MemGPT、

MemoryBank等共同构成了LLM智能体从“单任务执行”到“终身学习”、从“对话记忆”到“技能记
忆”、从“参数更新”到“上下文学习”的完整技术演进图谱，标志着LLM智能体研究进入“开放式终

身学习”的新阶段。
