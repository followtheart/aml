# v5：日期綁定、時間前提與有來源的回答

本輪依 v4 失敗案例開發；不使用新測試題來修改策略。核心及新增回答器均位於 `memory_connection/app`，不匯入 `memory_system`。舊系統只供評測層讀取既有回答提示詞與模型配置，源碼不修改。

## 改動

- 相對日期增加數字／英文數詞的日、週、月、年距離及上／下月、年。每個計算綁定該原始來源，年／月輸出區間，保留約略語意及逐字位置，不把月或年收窄成某一天。不支援的複合數詞或範圍不截取尾端誤算。原始來源不改寫。
- 原文重排直接比較原始問題與帶可讀來源日期的事件，不讓全域查詢時間冒充來源事件時間。仍使用整個事件與來源多樣性排序。
- 精判明確區分時間上界、下界與精確日期：已完成同一事件可限制開始時間，即使不足以回答精確日期也可保留 partial。維持事件／實體／媒介與模態區分，電影、書籍、計畫及已完成事件不互相代換。
- 停用預設的新穎來源保留槽。新策略只在原文補足查詢明示但目前精判池缺少的命名實體、引號短語或年份，且處於原文語義重排前 32 名時，最多置換最後兩個名額；不能損失已有線索。沒有缺失線索就不置換，無重排分數時也不強制加入。上限仍為 16，四組使用相同策略。
- 新增可選 `/answer` 與獨立 `answering.py`。將去重原文、來源時間、局部日期計算和引用放在一起，要求回答列出來源與缺失前提。來源編號可校驗，但不能宣稱語義已由程式證明。答案不寫回記憶；回答期間發生更新或刪除會使整份回應失效。
- 時間距離問題可取得伺服器計算的來源日期差，明確標示只屬於陳述日期，不能無依據地當成活動日期；仍需回答模型綁定正確事件。計算與來源共用證據位元組預算，不引入外部事實。

固定種子 20261027，按類型抽取 4 題時間推理、4 題跨會話、2 題知識更新及 2 題單會話使用者資訊；排除棄答題，要求所選歷史的 session ID 互不重疊。抽樣不依答案、證據位置或模型結果篩選。12 個問題各有獨立完整歷史，共 575 個 session、5,971 則原始消息。

保留全部干擾會話，不使用 oracle 子集。原文以最多 2,400 字元、優先換行的方式無損切成 6,762 個事件，兩版與四組共用相同切分及索引。資料集沒有時區的會話時鐘一致視為 UTC；這是適配假設，不推斷人物所在地時區。`has_answer` 與答案會話 ID 只供離線計分，不傳給記憶系統或回答器。

專案先前僅有 LongMemEval 論文／筆記，沒有其資料或評測 run；本輪首次下載。正式評測前，既有 LoCoMo 會話只用於開發校準，新抽取問題不進入開發迴圈。

校準中發現逐項 claims 的輸出協定容易讓無引用的算術小結使整份答案失敗，因此在正式凍結前簡化為一個來源引用清單。最後六個舊案例有四題答對，無輸出格式錯誤；相對年份與兩個月數問題修正，第三部劇本的事件綁定仍錯，圖片書名缺失仍無法解決。這些校準分數不能當作新資料成績。Judge 的年份精度與月數容差也在舊案例校準，未對新測試答案調整。

## 配對與歸因

以 v4 凍結快照為 before，v5 為 after；兩版都跑 C00／C10／C01／C11。寫入與查詢視角、向量共用，粗候選應一致，原文重排、精判及最後證據可以不同。v4 恢復其原設定的一個獨有來源槽，v5 使用兩個有條件線索補足名額。

每份搜尋結果再交叉使用 v4 回答器及 v5 有來源回答器：96 次搜尋、192 筆答案。主端到端比較是 v4 檢索＋v4 回答對 v5 檢索＋v5 回答；另外固定回答器比較檢索、固定證據比較回答，避免把讀取改善誤稱雙側召回改善。兩回答器都使用相同 chat 模型及同一個較嚴格的本地 Judge，要求完整事實與正確日期，不因話題接近就給分；這不是官方榜單分數，也不能直接與上一輪寬鬆 Judge 總分比較。

共同 top_k=10、證據 24,000 bytes、精判最多 16 事件／2 批。為完整長歷史設定搜尋 180 秒、召回 45 秒、重排 30 秒、精判 100 秒；精判批次 96,000 bytes、重排文件 18,000 bytes。兩版使用相同預算，這不是預設低延遲服務驗收。建庫 24 批並行，同題 8 組搜尋並行；共同預處理最多 3 次有界嘗試，每次費用與時間均記錄。

新原文較長，引用與封裝容量錯誤需列入結果，不能移除失敗樣本。評測保存已完成搜尋與兩回答器結果，續跑重用已完成步驟；程式及配置凍結後不能原地調參覆寫。所有提升都需同時報告配對勝負、原始證據覆蓋、失敗數、時間與成本。12 題是小型跨資料集驗證，不能作為全面優勢證明。

## 評分前修正紀錄

首段建庫完成 568／2,696 批時，尚未產生任何新題搜尋或評分。此時修正通用的小數／負數尾段誤解析防護，並將回答器 JSON 外框計入證據預算；92 項測試通過後重新凍結並冪等續跑。舊 manifest 與完整快照保存於 `pre-evaluation-freeze-1/`，`resumptions.jsonl` 記錄兩個改動檔案的前後雜湊。資料、抽樣、寫入與模型設定未變。停止舊子程序時，部分在途請求可能沒有回報用量，因此總成本只能報告已知用量估價，不會稱為完整帳單。

資料日期稽核發現 `gpt4_c27434e8` 與 `gpt4_fe651585` 含提問當天鐘點較晚的消息，後者包括一個答案會話。主結果保留發布資料的全部歷史；另報排除這兩段歷史的配對敏感度，不在看到成績後選擇性刪除個別錯題。
