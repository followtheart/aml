# 写入侧联想视图：第一阶段实施与诊断

2026-10-24。已实现独立、默认关闭的来源绑定多视图写入与召回。完整 61 题的隔离候选诊断没有通过进入下一阶段的条件，因此不启用生产，也不叠加新增查询侧联想或互补前提核验。该结果不是完整答题评测，不证明此机制在其他场景无效。

本报告记录第一阶段决策。随后用户明确要求尝试双侧，查询侧已作为独立开关实现并完成新的四组实验；见 [双侧说明](ASSOCIATION_VIEWS.md#查询侧与双侧)和[双侧诊断报告](DUAL_ASSOCIATION_REPORT.md)。第一阶段数据保留，不与新实验混算；下文“未实施”描述的是第一阶段结束时的状态。

## 实施范围

- 新 Add 在原有 staged 事务内按原文生成最多 3 个视图；视图与原始来源及 AMU 版本绑定，独立存储。
- 每个视图有逐字、唯一的原文锚点；无效视图单独拒绝。生成或 embedding 批次失败不发布该批视图。
- 新召回通道复用既有查询向量，过滤失效版本、撤回、过期、敏感和跨用户来源。最大值合并视图分数，同一原始来源只提供一个候选席位。
- 图融合保留原有语义分数，取其与折扣后联想分数的最大值。生成文本不进入事实、画像、图三元组或最终原文审查；原精排与打包保持现有逻辑。
- 历史快照、事务回滚、并发删除、硬删除和运行版本元数据已覆盖新索引。详见 [实现说明](ASSOCIATION_VIEWS.md)。

## 数据与实验边界

使用完整 `https-validation-baseline-20261024` 的两个会话、474 条消息、29 次历史 Add、61 个问题。原数据库通过 SQLite 只读备份复制到隔离目录；没有重新抽取 AMU，也没有读写生产数据库。

索引处理全部 474 条消息，生成 **422 个合格视图、698 个 AMU 版本绑定**。100 条来源没有有效衍生视图，可能包括模型返回空结果或全部视图被校验拒绝。没有超长来源跳过、批次额度遗漏或整批生成/embedding 失败。原 AMU、原文、来源绑定、三元组、请求和版本历史的内容指纹前后相同。

每题固定历史查询规划及原召回通道，共用一次新计算的查询向量；控制组不追加视图，实验组追加。使用同一模型与排名预算，按题交替两组执行顺序，执行真实 qwen3-rerank，在主审调用前停止。参考标注仅在独立 analyze 阶段读取。

控制组粗排候选集合及顺序在 **49/61** 题与历史记录完全一致；另外 12 题存在复现差异，未逐项归因。因此本实验是同一次重建流程内的配对诊断，不是历史管线的逐字节完整重放。两组共用的原始查询向量未单独归档，候选、CE 记录、主审输入、代码及脚本指纹均已保存。

主审输入新增 Q283、Q339，丢失 Q307、Q322，净增为 0。实验改变了全部 61 题的粗排顺序或集合、56 题的精排顺序或集合、53 题的主审输入顺序或集合，却没有增加最终测量阶段的参考覆盖。CE 全部完成，无调用失败。

预先设置的进入下一阶段条件为：主审输入增加参考覆盖、不丢失控制组参考且无 CE 故障。本轮有 2 题新增、2 题丢失，**未通过**。没有运行主审、回答器或新增 HTTPS 答题评测，不能报告新的准确率、最终返回证据覆盖或在线延迟。

正式索引记录 252 次供应商调用、144,402 个记录 token；配对诊断记录 445 次调用、3,122,868 个记录 token。后者包含 CE 的供应商用量或输入估算，不是统一计费口径，不作为账单。此前排除的开发索引及单批探测另有调用，不计入上述正式两阶段数字。

## 验证及当前决策

- 新增 **27 项测试通过**；存储、生命周期、来源召回、搜索、图存储、原文审查、HTTP 契约等另外 155 项相关检查通过。
- `selftest_graph_cascade.py` 18 项中有 2 项失败；在未修改的 HEAD `c6620e7` 上复现相同失败。原因涉及旧测试预期粗排 50 条，而当前既有默认扩展至 58 条，以及扩展候选进入精排；本次没有增加失败或更改这些既有默认。
- 正式诊断结束后，应用和提示词哈希与 replay 冻结记录一致；所有 61 个配对结果无遗漏、无重复。
- `AML_ASSOCIATION_WRITE=0`、`AML_ASSOCIATION_RECALL=0` 继续保持默认。生产 `memory-system-https.service` 没有重启或开启新机制，443 健康检查正常。

本次保留可复核的实验实现。后续若继续，需要先解释被挤出的来源及候选分数变化，并在固定 CE 输出或重复配对下确认效果；不根据本轮两道新增题调参后重复宣称未测收益。查询侧联想和联合前提核验仍是未实施的后续假设。
