# 候選降噪優化：single_pass_v4

完成日期：2026-09-18。本輪實作 H／I／J 的候選降噪，保留一次規劃、一次召回、單輪分批重排及完整證據包的架構。

## 實作內容

| 節點 | 改動 | 保護措施 |
|---|---|---|
| H 查詢規劃 | 新增與選項對齊的 `option_queries`；以短前提取代長篇建議，最多六條查詢 | 缺失／無效項目回退到選項本身；保留否定／條件；查詢不寫成記憶 |
| H 畫像隔離 | 選擇題不再注入畫像 digest；無選項問題只用有詞面關聯的畫像 | 避免錯誤養狗畫像混入廚房查詢；不宣稱已修正庫內錯誤畫像 |
| I 路徑預算 | 向量 40、原文 40、全文 20、畫像 8；路徑配額與最終 top_k 分離 | 使用者規則獨立保留；冷資料與既有歷史、敏感、版本過濾仍適用 |
| I 按需擴展 | 多跳／敘事／文件，或直接詞面命中少於 3 個 ID 時啟用 graph／scene，合計最多 12 | 不新增規劃或充分性模型調用；稀疏命中仍有擴展路徑 |
| J 來源預覽 | 以句子局部匹配密度替代整篇詞數；預覽與裝包使用相同短查詢 | 保留同段人物引用開頭、否定與明確 evidence；支援英文及中文引用開頭 |
| J 去重 | 重複來源正文不重占名額；同來源集合、預覽與語義狀態的 episode 合併 | 所有來源引用及 equivalent_ids 保留；不同角色、說話者、時間或狀態不折疊 |
| 可觀測性 | 版本升為 `single_pass_v4`，記錄 `query_specs`、`expansion` 與配額 | 可核對實際查詢、選項對應、回退及擴展原因 |

配額是可配置的初始值，不是已校準的最佳值。`top_k` 是最終返回上限，不保證填滿；需要大型候選集時應明確調整路徑配額。
