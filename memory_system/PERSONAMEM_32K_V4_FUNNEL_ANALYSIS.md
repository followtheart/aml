## 7. 下一輪應優先驗證的修正

1. **先修重排輸出及尾批可靠性。** 動態約束 score 陣列長度；避免 1–2 項微小尾批；對單批格式錯誤做有界恢復。若保留其他成功批次，必須明確隔離「模型相關性」與「回退排序分」，不能混合成同一分數。驗證 Q13／21／24 的原始批次輸入。
2. **把選項覆蓋納入重排池與同分選擇。** Q14 表示總候選少、direct_count 多仍可漏掉關鍵活動。需要保留不同選項的支持／反證來源，而不只保留整體 RRF 頭部；Q22 的 0.1 同分時應重視原始使用者線索、來源獨立性，避免 assistant 解釋先占滿弱回退名額。
3. **以判別證據校準評分。** 直接建立 Q4 資產 projects、Q15 湖水细菌、Q20 黑膠與籃球的反例；區分主題重合、個人興趣、已確認習慣，以及反證。不能只再提高或降低統一閾值。
4. **評測回答端的主體／前提使用。** 固定 Q11 Marcus、Q15 騎行、Q16 氣喘、Q9 遺忘的完整包，檢查回答是否保持人物歸屬、採納直接證據、排除已遺忘特徵。這能把 L 的問題與 H–K 分開。
5. **寫入校驗與實驗控制同步補齊。** 修正照片 owner→使用者養狗等不成立的映射；對弱金標前提另標證據強度。接著固定 DB、問題、查詢或候選池做分階段對照，再跑整體評測並保留原始日誌。
