# 精读笔记：Agent Workflow Memory (AWM)

- 出处：ICML 2025（arXiv:2409.07429，CMU/MIT）；论文：`papers/agent-workflow-memory.pdf`
- 一句话：从历史轨迹中归纳"可复用工作流（workflow）"，推理时选择性注入指导动作生成；Mind2Web/WebArena 相对成功率 +24.6%/+51.1%。

## 核心机制

- **工作流归纳**：离线（从训练样本）或在线（从测试查询即时）归纳子程序级例程——比"事实"更高一层的记忆单元。
- **选择性供给**：检索与当前任务相关的工作流注入上下文。
- 在线 AWM 跨任务/跨网站/跨领域稳健泛化。

## 对 AML 方案的可复用点

- Coding Track（SWEContextBench）的关键参照：工程经验记忆不应只是事实，还应有**过程性记忆**（"修这类 bug 的标准流程"）。AMU 增加 type=workflow/procedure。
- 文本 Track 的规则执行维度同理：规则/工作流应作为独立记忆类型存储与直通召回（方案 5.2 第 6 路"规则直通"）。
- 提示词设计：轨迹→工作流的归纳提示词（输入动作序列，输出带前提条件与步骤的流程描述）。
