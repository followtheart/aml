# 精读笔记：ExpeL — LLM Agents Are Experiential Learners

- 出处：AAAI 2024（arXiv:2308.10144，清华）；论文：`papers/expel.pdf`
- 一句话：不更新参数的经验学习——agent 自主从训练任务中收集经验、用自然语言提炼"洞察（insights）"，推理时召回洞察+成功轨迹指导决策。

## 核心机制

- **经验池**：成功/失败轨迹都存，失败轨迹用于对比提炼教训。
- **洞察提炼**：LLM 对成功-失败轨迹对做对比分析，归纳出可迁移的自然语言规则；持续迭代时合并/去重/修订洞察列表。
- **推理时召回**：检索相关洞察 + 相似成功轨迹作为 few-shot。

## 对 AML 方案的可复用点

- **洞察即规则记忆**：AMU 的 type=rule 可采用 ExpeL 式自然语言规则形态（"当 X 时，应 Y 因为 Z"）——对应 AML 的规则执行维度。
- **成败对比提炼**是 Coding Track 调试经验复用的经典范式：历史任务中"这个修法失败→换那个成功"应提炼为规则而非只存原始轨迹。
- 提示词设计：对比式提炼提示词（给定成功与失败轨迹，产出可迁移规则列表，并支持对已有规则列表的 add/edit/upvote/downvote 式修订）。
