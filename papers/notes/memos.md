# 精读笔记：MemOS — A Memory OS for AI System

- 出处：arXiv:2507.03724（MemTensor/上海算法创新研究院等，2025）；论文：`papers/memos.pdf`
- 一句话：把记忆提升为操作系统级资源——统一的 MemCube 抽象封装参数化/激活/明文三种记忆形态，带生命周期管理与调度。

## 核心机制

- **MemCube**：统一记忆容器（元数据+内容+溯源），支持跨形态转换（明文记忆 ↔ 激活/参数化）。
- 记忆调度器（类 OS scheduler）：按任务需求加载/卸载 MemCube。
- 强调治理：生命周期、权限、溯源——与 AML 的审计/治理要求同向。

## 对 AML 方案的可复用点

- **MemCube 元数据设计**（来源、时间、权限、版本）与 AMU 的 raw_refs/valid_from-to/supersedes 设计互相印证。
- AML 场景只用"明文记忆"形态，参数化/激活记忆不适用；其价值在工程抽象与治理视角。
- 37 页长文，系统工程参考重于算法创新。
