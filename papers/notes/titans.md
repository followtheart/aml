# 精读笔记：Titans — Learning to Memorize at Test Time

- 出处：arXiv:2501.00663（Google Research, 2025）；论文：`papers/titans.pdf`
- 一句话：神经长期记忆模块——测试时学习记忆历史上下文，与注意力（短期记忆）互补；训练可并行、推理快。

## 对 AML 方案的价值

- 模型架构级创新，AML 不可用；视野拓展。
- 概念框架有价值：**attention = 短期记忆（精确但有界），神经记忆 = 长期记忆（压缩但持久）**——方案的分层叙事可借用此类比：会话内上下文（短期）/ AMU 外部库（长期）。
- "惊讶度（surprise）"驱动写入的思想 → 可启发 AMU 抽取的"显著性过滤"：与已有记忆高度冗余的内容降低优先级（治理去重的信号之一）。
